# 01 · Voice & Tone

> Voice is constant. Tone flexes with context. Both apply to marketing copy **and** UI text.

## Voice attributes
| Attribute | Do | Don't |
| --- | --- | --- |
| **Clear** | Short sentences, plain words, one idea each | Jargon, acronyms, nested clauses |
| **Warm** | Talk like a helpful person; contractions welcome | Corporate passive voice, fake enthusiasm |
| **Confident** | State things directly | Hedge ("we think maybe…"), over-explain |
| **Optimistic** | Focus on what's possible | Cheesy exclamation marks, hype |

## Tone by context
| Context | Tone | Example |
| --- | --- | --- |
| Marketing | Bold, energising | "Get set up in five minutes." |
| Product UI | Helpful, direct | "Save changes" · "Add a teammate" |
| Onboarding | Encouraging | "Nice — your first project is live." |
| Errors | Calm, reassuring, actionable | "We couldn't save that. Check your connection and try again." |
| Support / legal | Straightforward | "Your data is deleted within 30 days." |

## Writing rules
- **Sentence case** for headlines, buttons, labels. Capitalise only proper nouns and product names.
- Numerals for numbers (3, not three), except at sentence start.
- One exclamation mark per page, maximum. None in error messages.
- Active voice by default. "You can export…" not "Exports can be made…"
- Address the user as **you**; we are **we**.
- Avoid "please", "simply", "just", "easy" — show it, don't say it.

## UX microcopy patterns
| Element | Rule | Example |
| --- | --- | --- |
| Buttons | Verb + object, ≤ 3 words | "Create project", "Send invite" |
| Destructive buttons | Name the consequence | "Delete project" (not "OK") |
| Empty states | What it is + how to start | "No projects yet. Create your first one to get started." |
| Errors | What happened + what to do | "That email is already in use. Try signing in instead." |
| Success toasts | Past tense, short | "Invite sent" |
| Loading | Present continuous | "Saving…" |
| Placeholders | Example, not instruction | "name@company.com" |
| Tooltips | ≤ 12 words, no full stop | "Only admins can change billing" |

## Words we use / avoid
| Use | Avoid |
| --- | --- |
| sign in / sign out | log in / log out |
| teammate | user, member |
| workspace | account, tenant |
| remove | delete (unless permanent) |
